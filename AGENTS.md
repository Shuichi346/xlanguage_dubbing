# AGENTS.md

Project instructions for coding agents working in this repository.

- Preserve the `ENABLE_AUDIO_SEPARATION` fallback: when it is `false`, the pipeline must use the original media audio for ASR, reference extraction, and final background mixing.
- Keep audio-separation and raw-audio temporary outputs isolated. The raw-audio mode uses `temp/<video>_rawaudio`; separated mode uses `temp/<video>`.
- Apply `ORIGINAL_VOLUME` only to raw original audio. When `ENABLE_AUDIO_SEPARATION=true`, mix the separated background stem at full volume unless a new explicit background-volume setting is added.
- Do not remove the Demucs `--two-stems vocals` contract unless the pipeline is updated to consume a different voice/background stem layout.
- Keep Demucs model/device configurable through `DEMUCS_MODEL` and `DEMUCS_DEVICE`; do not hard-code `cpu` or `mps` in the separation command.
- Keep `scripts/run_config_matrix.py` aligned with supported values whenever `ASR_ENGINE`, `ENABLE_AUDIO_SEPARATION`, or `TTS_ENGINE` options change.
- Keep `ASR_ENGINE=nemo-speech` on the installed NeMo-Speech.cpp CLI with explicit ASR and diarization models. Parse JSON word times in seconds and 1-based speaker tags (1–8), map them to `SPEAKER_00`–`SPEAKER_07`, and skip pyannote. Reference clips use NeMo without diarization; device values are `metal` or `cpu`.
- Keep NeMo checkpoints under the audio mode's `nemo-speech/` subdirectory to avoid reusing another ASR engine's segments, translations, or TTS references.
- Keep VoxCPM2 cloning in Controllable Cloning mode: pass `reference_wav_path` only, selecting per-segment references in original-voice mode and the same designed reference for every utterance of a speaker in voice-design mode. Keep VoxCPM2 reference cache artifacts under `voxcpm2_*` names.
- Install `Shuichi346/Irodori-TTS-Server-nonWatermark` at the server revision pinned in `scripts/setup_irodori.sh`, using its committed `uv.lock` to select the `Shuichi346/Irodori-TTS-nonWatermark` inference dependency. Keep `IRODORI_TTS_DIR` defaulted to `./Irodori-TTS-Server-nonWatermark`. The setup helper uses locked CPU sync, rejects other repository origins, and preserves local edits before changing revisions; keep the previous official-server checkout intact rather than overwriting it.
- Keep Irodori-TTS-v4.1-Small-MF in server API mode with a MeanFlow-capable Irodori-TTS inference library: use `Aratako/Irodori-TTS-v4.1-Small-MF`, pass each speaker's cached reference latent as `irodori.ref_latent`, default to `4` steps, omit RF-only Sway/CFG controls, and do not set fixed `seconds`. Caption is allowed only when generating the initial designed voice without a reference; subsequent cloning requests omit Caption / Style Prompt.
- Keep original-voice Irodori render caches and final output names isolated by effective model/sampling settings. Include reference latent hashes and translated lines in render fingerprints; inactive MeanFlow Sway settings must not invalidate voices. For pipeline-owned startup, clear `IRODORI_CHECKPOINT` and set `IRODORI_DEFAULT_NUM_STEPS` to match the selected request profile. Reject an already running server that reports another checkpoint; never stop externally managed servers.
- Keep `ENABLE_VOICE_DESIGN` opt-in and limited to `OUTPUT_LANG=ja/en`; Irodori remains Japanese-only. Generate one target-language sample per speaker, persist it atomically, and clear original segment references before cloning. Unknown attributes use an adult male; OmniVoice uses only gender, young adult/middle-aged, and moderate-pitch attributes.
- Keep designed voices and render checkpoints isolated by engine, language, settings, and reference fingerprints. Release the age/gender estimator before TTS; stop only a pipeline-owned Irodori design server before the codec-only latent worker. Preserve generated voices on resume, including uncertainty fallbacks; changing `VOICE_DESIGN_SEED` creates a new voice set.
- Download age/gender weights only from the official `audeering/wav2vec2-large-robust-24-ft-age-gender` Hugging Face repository at the revision pinned in `tts/age_gender.py`. Load both custom prediction heads from safetensors on CPU; return raw gender logits for a single softmax. Use audonnx only for user-supplied or existing local ONNX exports; do not use third-party mirrors or automatically fall back to a Zenodo download.
- Keep persistent age/gender weights in the project-root `models/` directory, which is excluded from Git; resolve relative model paths against the project root rather than the job's working directory. Keep generated voice-design clone references and latents in `temp/`.
- Generate Irodori reference latents in a short-lived process using the Irodori-TTS-Server environment before starting the long-running TTS server. Load only the DACVAE codec, encode each selected short utterance separately as 48 kHz mono FP32 with deterministic encoding and `normalize_db=-16.0`, then concatenate the latents in utterance order.
- Limit Irodori reference latents to 120 seconds, compose them from multiple short utterances by the same speaker, and keep one validated, atomically-written `.pt` cache per speaker under `speaker_refs`.
- Keep the CAT-Translate-7b prompt aligned with CyberAgent's 7B-specific chat template. Pass the complete prompt as tokens created with `add_bos=False` and `special=True` because the template already contains `<s>`.
- Keep the TranslateGemma text prompt aligned with the structured template embedded in its GGUF: preserve source/target language codes, three newlines before source text, and Gemma turn markers. Its prompt omits a textual BOS because `llama-cpp-python` prepends one.
- Concatenate silence and TTS FLAC chunks through independent decoders; their STREAMINFO block sizes may differ. Validate joined-track sample counts before cache reuse and publish completed audio atomically.
- Use `AudioDecoder.get_all_samples()` in `diarization/speaker.py`; preserve fallback audio loading when the native TorchCodec library is unavailable.
- Keep the worker-only `irodori_tts.codec` dependency in the separate Irodori server environment. Keep any corresponding type-check exception scoped to that import and explain the environment boundary.
- Install project lint/type tools with `uv sync --only-group dev --inexact`. Run `uv run --no-sync ruff check src tests scripts` and `uv run --no-sync ty check` for quick checks after Python edits; report existing diagnostics rather than silently suppressing them.

Preserve existing dated/versioned history and classify undated historical entries under `## DATE UNKNOWN` with `### Fixed`, `### Added`, `### Changed`, and `### Removed`. Do not create new `Unreleased` sections.

- Read only relevant sections needed to avoid duplicates or contradictions. Reuse task evidence; inspect the smallest relevant diff or source excerpt only for missing material facts, without routinely rebuilding history.
